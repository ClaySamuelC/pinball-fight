# Pinball Nexus

A browser game for two players. Each person plays a pinball table. Hits summon fighters into a shared lane.

Play: https://claysamuelc.github.io/pinball-fight/

## Play on your machine

```bash
npm install
npm run dev
```

## Update the public game

```bash
npm run deploy
```

That builds the site and publishes the `dist` folder to GitHub Pages.
